# ✊ Rock Paper Scissors Game

A fun and interactive **Rock Paper Scissors** game built using Python and Pygame. Play against the computer, compete to reach 3 points first, and enjoy a visually appealing graphical user interface.

## 🎮 Features

- **Player vs Computer:** Play against a computer opponent.
- **Interactive GUI:** User-friendly interface built with Pygame.
- **Random Computer Moves:** Computer randomly selects Rock, Paper, or Scissors.
- **Live Scoreboard:** Tracks both player and computer scores.
- **Round Counter:** Displays the current round.
- **Match System:** First to score 3 points wins the match.
- **Restart Option:** Restart the game anytime with a single click.
- **Colorful Design:** Modern dark-themed interface with attractive colors and emojis.

## 🛠️ Technologies Used

- **Python** – Core programming language.
- **Pygame** – Graphics, user interaction, and game development.
- **Random Module** – Generates random computer choices.
- **Sys Module** – Handles program termination.

## 📸 Game Preview

The game features:
- A scoreboard displaying player and computer scores.

- Visual representation of both players' choices.
- Real-time game results.
- A restart button to play again.

## 📋 Game Rules

The classic Rock Paper Scissors rules apply:

| Choice | Beats |
|---|---|
| ✊ Rock | ✌ Scissors |
| ✋ Paper | ✊ Rock |
| ✌ Scissors | ✋ Paper |

- If both players choose the same option, the round is a draw.
- Winning a round earns 1 point.
- The first player to reach 3 points wins the match.

## 🕹️ How to Play

1. Run the Python program.
2. Choose one of the three options: Rock, Paper, or Scissors.
3. The computer will randomly select its move.
4. The winner of the round will be displayed.
5. Keep playing until either you or the computer reaches 3 points.
6. Click the **RESTART** button to start a new match.
